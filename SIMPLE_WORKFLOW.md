## 🎯 **Three Simple Commands**

### **1. Work on Beta** (Chrome Web Store version)

```bash
/home/user/work-beta
```

Opens beta folder. Edit files, test in Chrome, done.

---

### **2. Work on Full** (All features version)

```bash
/home/user/work-full
```

Opens full folder. Add features, test in Chrome, done.

---

### **3. Create ZIP files** (for download/submission)

```bash
/home/user/make-zips
```

Creates both ZIP files automatically. Use for Chrome Web Store submission or sharing.

---

## 🎨 **OR Use the Easy Manager** (Interactive Menu)

```bash
cd /home/user/chrome_dev_ext
./easy-manager.sh
```

Shows a menu:
```
1️⃣  Work on BETA version
2️⃣  Work on FULL version
3️⃣  Create ZIP files
4️⃣  Show current status
5️⃣  Exit
```

Just pick a number!

## 📦 **Your Directories**

```
/home/user/chrome_dev_ext_BETA/    ← Beta version (simple)
/home/user/chrome_dev_ext_FULL/    ← Full version (complex)
```

**To load in Chrome:**
1. Open `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select either folder above
